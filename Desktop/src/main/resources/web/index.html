Carpeta de salida

Dónde se guardan guiones, imágenes, miniaturas y vídeos.

Cada pack se guarda en su propia subcarpeta con la fecha y el titular.

Las claves se guardan cifradas (AES-256-GCM) en tu perfil de Windows. Solo el motor local de Pulse Studio las usa para llamar a Groq, Pexels y Hugging Face: nunca se envían a la interfaz.
